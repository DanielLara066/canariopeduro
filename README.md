# Canário Pé Duro

Esboço de uma vitrine para acessórios de canário-belga. Três categorias e 30 produtos demonstrativos, com espaço para fotos, preços e história da loja.

## Desenvolvimento

Node.js >= 22.13.0 e pnpm. Execute `pnpm install`, `pnpm dev` e `pnpm build` para gerar a versão estática.

## Conteúdo

- `app/page.tsx`: catálogo e textos.
- `app/globals.css`: identidade visual e versões para celular.
- `public/images`: fotos provisórias.

Os botões de compra estão desativados intencionalmente. A integração Yampi ainda não foi implementada. Para vendas reais serão necessários produtos, preços, fretes e checkout configurados. Não inclua credenciais no código do navegador ou no Git.
